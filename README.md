# 🎒 Study on the Go 🚗

A portable, educational game built for the **Arduboy** hand-held console. This software was created as a project for Hack Club Stardance!

## 📝 Project Description
"Study on the Go" turns learning into a fun, mobile experience. Designed specifically for the retro hardware limitations of the Arduboy, this game allows users to practice and study topics while on the move using a simple, intuitive button-controlled interface.

## 🕹️ How to Play
* Use the **D-Pad (Arrow Keys)** to navigate menus and select answers.
* Press the **A / B Buttons** to confirm your choices and progress through the game.
* Track your score as you play and try to get a perfect run!

## 🛠️ Built With
* **Arduboy Web Editor** - Used for writing and compiling the software.
* **Arduino C++ / Arduboy Library** - The core language and tools used to control the screen and buttons.

## 🚀 How to Run the Code
1. Download the source code file from this repository.
2. Open the [Arduboy Web Editor](https://cloud.arduboy.com/) or Arduino IDE.
3. Import or open the project file.
4. Upload it to your physical Arduboy device or run it directly in an online emulator!
